# mm-sim

A market-making research lab. Build bots that quote bid and ask prices, manage
inventory risk and avoid getting picked off by informed traders, then pit them
against each other.

- Event-driven simulator with realistic background order flow
- Classic models implemented from the papers: Avellaneda-Stoikov, Guéant-Lehalle-Fernandez-Tapia, Glosten-Milgrom
- Adverse selection, markouts and P&L attribution
- Runs on the C++ [orderbook](https://github.com/Lemypoo/orderbook) engine and replays real NASDAQ data

> Just getting started.
